> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cerrar VivesPong 3D 0.1 con rojo-verde en cada comportamiento, usando solo `McpTestSuite` y el runner Godot AI.

**Architecture:** `MatchState` (puntos) + `CourtExtents` (números) + `Paddle`/`Ball` (cinemática) + `ScoreUI` (copy) + `VivesPongMain` (fases). `Ball` no puntúa. Tests `preload`an scripts; no dependen de `class_name` fresco.

**Tech Stack:** Godot 4.7.1, GDScript, Jolt, Forward+, plugin `addons/godot_ai` 3.1.5.

**Spec:** [docs/sdd-vivespong-0.1.md](../../sdd-vivespong-0.1.md) (copia canónica: [docs/superpowers/specs/2026-08-15-vivespong-0.1-design.md](../specs/2026-08-15-vivespong-0.1-design.md))

## Global Constraints

- GDScript only. No GUT/WAT/C#/addons extra. No editar `addons/godot_ai/` ni el dump `Godot-MCP-*`.
- Tests en `res://tests/test_*.gd`, `@tool`, `extends McpTestSuite`, `preload("res://…")`.
- `assert_eq` solo para `int` / `bool` / `String` / enums. Floats y `Vector3`: `assert_true(is_equal_approx(a, b), "msg")`.
- 0 asserts = FAIL. Tras `class_name` nuevo: `filesystem_manage(op="scan")`.
- Correr: `godot-ai__test_run` con `suite=` (igualdad exacta) y `test_name=` (substring).
- No `Main.tscn` ni `application/run/main_scene` antes de la Task 8 (PR-6b).
- Input Map only. Nunca keycodes crudos en gameplay.
- `Ball` no declara `var velocity`. Palas: `apply_axis` no llama `move_and_slide`.
- Bitmasks: walls=1, paddles=2, ball=4, goals=8. Mask del gol = layer 3 (`set_collision_mask_value(3, true)`), nunca el entero `3`.
- Defaults de pista: 12×20 m, v=8.0 / +0.5 / max 20.0, saque 1.0 s (OQ-1.A / OQ-5.A).
- Git no está inicializado: Task 0 lo crea. Commits posteriores asumen que existe.
